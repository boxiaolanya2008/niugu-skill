# niugu-svg-graphics — SVG 架构图与流程图

## 〇、优先级声明

**架构图与流程图一律手工 SVG，禁止 Mermaid**。理由：Mermaid 布局不可控、样式平庸、长文本溢出无解；SVG 逐元素可控，可达到工程美学标准。

---

## 一、画布与文件结构

每个 SVG 必须满足：

1. 根元素显式声明 `viewBox="0 0 W H"` 与 `xmlns="http://www.w3.org/2000/svg"`。
2. 字体族声明：`font-family="'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif"`。
3. 背景整幅 `<rect>` 铺底色，不留透明底。
4. 箭头统一用 `<defs><marker>` 定义一次、全程引用 `marker-end`。
5. 交付前必须通过 XML 解析（well-formed），且图例齐全。

## 二、配色令牌（与 niugu-interface 同源）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 底 | `#faf7f2` | 整幅背景 |
| 分层底 | `#f3ece2` | 分组带背景 |
| 节点底 | `#ffffff` | 普通节点填充 |
| 墨 | `#2d2a26` | 标题与节点主文字 |
| 次级 | `#8a8378` | 说明文字、次要线 |
| 强调 | `#c96f2e` | 强调节点描边、流转箭头 |
| 边线 | `#d8cfbe` | 分组带与辅助节点描边 |

色相 ≤3；禁止渐变填充节点、禁止阴影滤镜。

## 三、几何与排布

- 节点：`<rect>` + `<text>` 组合，圆角 `rx="8"`，描边 1.5~2px。
- 节点内两行文字：标题（13~15px，700）+ 说明（10~11px，次级色），行距 20~22px。
- 文字 `text-anchor="middle"`，垂直位置 = 节点顶 + 高度 × 0.42（标题）/+0.66（说明）。
- **文字边界自检**：按 11px 字号 ≈ 6px/汉字宽估算，文字宽 ≤ 节点宽 −24px，否则加宽节点或精简文案。
- 排布对齐：同行节点 y 一致、等间距；间距取 8 的倍数。
- 连线：直线用 `<line>`，折线用 `<path>` + `fill="none"`；虚线 `stroke-dasharray="5 4"` 表示回环/弱依赖。

## 四、三种图式模板

### 1. 流水线（Pipeline）

```
[阶段1] --门禁--> [阶段2] --门禁--> … 
失败回路：虚线从后段折回前段，从节点底部下探 30px 再水平折回
```
- 门禁标签写在线上方 10px 处，10px 字号，强调色。
- 回环说明文字写在折线水平段下方 14px。

### 2. 分层架构（Layered）

- 自上而下：应用层 / 服务层 / 数据层，每层一个分组带 `<rect>`（分层底色）+ 左上角层名标签。
- 层内节点横排等距；跨层依赖箭头垂直向下，禁止交叉超过 2 次。

### 3. 流程判定（Flowchart）

- 判定用菱形（`<path>` 手工四点折线），Yes/No 标签贴在分支线起点 10px 处。
- 分支汇合点用小实心圆 `r="3"` 标注。

## 五、验收清单（每次交付前）

- [ ] 根元素含 `viewBox` 与 `xmlns`，背景铺满
- [ ] 箭头 marker 定义于 `<defs>`，全程引用一致
- [ ] 所有文字未溢出节点边界（按估宽规则复核）
- [ ] 同级节点 y 对齐、间距为 8 的倍数
- [ ] 色相 ≤3，与配色令牌表一致
- [ ] 有图例或连线语义自明
- [ ] XML 解析通过，浏览器可独立渲染、无外部依赖
- [ ] 图内如出现 `{{variable_name}}` 占位符逐字保留
