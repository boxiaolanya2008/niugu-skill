# niugu-interface — 界面视觉纪律

## 〇、优先级声明

本技能**高于**模型默认的组件使用与配色惯性。禁止无理由套用 UI 库默认外观、禁止霓虹渐变、禁止杂乱撞色。

---

## 一、配色（最高优先级）

1. **UI 组件色相 ≤3**：主色 + 辅助色 + 中性色，仅此三类。
2. **暖色优先**：米白、暖灰、赭橙基调；冷色仅在与品牌强绑定时使用。
3. **品牌视觉开闸**（唯一例外）：logo、应用图标、落地页 Hero 主视觉允许多色渐变与更广色域——现代图标风格（白 squircle 容器 + 高饱和渐变字形）是标准参考。开闸范围仅限品牌层，不外溢到正文、表单、列表等 UI 组件。
4. **禁止**：
   - UI 组件上的霓虹渐变与撞色堆叠（品牌视觉除外）
   - 一屏超过 3 种主视觉色
   - 纯黑 `#000000` 文字（用暖墨 `#2d2a26` 替代）
   - 纯白背景大面积留白与低对比灰字叠加
5. **对比度达 WCAG AA**：正文 ≥4.5:1，大标题 ≥3:1。交付前必须自检。

推荐基线色板（可整体替换但结构不变）：
- 底色 `#faf7f2`（米白）/ 分层底 `#f3ece2`
- 墨色 `#2d2a26`（正文）/ 次级 `#8a8378`
- 强调 `#c96f2e`（暖橙，仅用于关键动作与当前态）

品牌渐变参考（图标/hero 用）：`#1f7cf5 → #6aa8ff → #b18cff → #8b2ff0`（蓝→紫对角），或 `#8a7ff0 → #e8825a`（紫→橙冷暖过渡）。

## 二、字体（按任务气质选择）

| 任务气质 | 字体方向 | 示例 |
| --- | --- | --- |
| 工具/效率 | 无衬线、中性、高 x-height | Inter, system-ui |
| 内容/阅读 | 正文衬线或人文无衬线 | Georgia, Source Han Serif |
| 品牌/落地页 | 有性格的展示字体，仅标题用 | 标题 1 款 + 正文 1 款，最多两款 |

规则：正文 ≥16px、行高 1.5~1.7；字号阶梯 ≤6 级；禁止用 `italic`/`bold` 补偿字号层级。

## 三、间距与布局

- **节奏刻度**：4 / 8 / 12 / 16 / 24 / 32 / 48，禁止随手魔法数。
- 容器最大宽度：正文阅读 65~75ch，工具界面 ≤1280px。
- 对齐方式一屏内 ≤2 种；留白是设计手段，不为填满而堆组件。
- 网格：列间距取刻度值，断点 3 档足够（移动 / 平板 / 桌面）。

## 四、组件纪律

- 禁止无理由套默认组件库外观：组件必须体现本技能配色与间距刻度。
- 按钮：一屏一个主按钮（强调色），次级用描边或文本按钮。
- 表单：标签上置，错误就地显示，禁止仅靠颜色表达状态（加图标/文字）。
- 列表与卡片：同级视觉权重一致，禁止随机强调。
- 阴影：低透明度、大模糊、小位移（如 `0 4px 12px rgba(45,42,38,.08)`），禁止重投影。
- 圆角：统一一档（6~10px），禁止混用直角与大圆角。

## 五、动效

- 时长 150~250ms，缓动用 `ease-out` 系。
- 动效只用于反馈（进入、切换、确认），禁止装饰性循环动画。
- 遵守 `prefers-reduced-motion`。

## 六、现代图标设计（品牌开闸区）

标准参考：**白色 squircle 容器 + 高饱和多色渐变字形**（现代应用图标范式）。

容器：
- squircle（超椭圆圆角）：圆角半径 ≈ 边长 22%~24%（512px 图标取 `rx ≈ 112`），圆角过渡平滑无"枕形"感。
- 容器底：白色或近白（`#ffffff` / `#fbfbfd`）；深色容器仅用于图标展示页的衬底，不作为图标本体。
- 外边距：字形四周留白 ≈ 边长 18%~22%，禁止顶边。

字形：
- 用**粗圆笔触**构建（stroke-width ≈ 边长 12%~15%，`stroke-linecap="round"`、`stroke-linejoin="round"`），杜绝细线条与尖锐转角。
- 单一字形主体 + 对角线性渐变（2~4 个 stop，蓝→紫 / 紫→橙 等相邻色相过渡，禁止互补色硬切）。
- 渐变方向：左下→右上或左上→右下，保持对角动势；字形重心居中或略偏上。
- 层次可选：字形上叠一层半透明浅色同构形状制造前后景（参考双层 ribbon 效果），透明度 30%~45%。
- 禁止：细描边图标风、扁平淡色块、金属质感、投影堆叠。

尺寸与交付：
- 主交付 SVG（矢量、可缩放），PNG 导出 512 / 192 / 96 三档。
- 深浅双底各验一次：白底与黑底上字形对比度均需充足。

## 七、落地页 Hero（品牌开闸区）

标准参考：**浅灰底 + 悬浮胶囊导航 + 渐变品牌字 + 右侧带光晕的主视觉**（现代组件库落地页范式）。

结构（自上而下）：
1. **悬浮胶囊导航**：整条圆角胶囊（`border-radius: 全圆`），白底、轻阴影、左右留白 ≈ 24px；左端 wordmark（粗体、品牌色或渐变字），右端 2~3 个文字链接 + 主题切换；与页面顶部间距 ≈ 20px，不贴边通栏。
2. **左侧文案区**：
   - 品牌名/产品名：粗体展示字，可用品牌渐变文字（`background-clip: text`）；
   - 主标题：40~56px，重字重，深墨色，两行以内；
   - 副标题：16~18px，次级灰，一句话；
   - 按钮组：主按钮（品牌色实底胶囊 + 图标）+ 次按钮（白底胶囊），间距 12px。
3. **右侧主视觉**：大尺寸图标/立体字形（占屏 35%~45%），背后垫**柔和径向光晕**（2~3 色低透明度模糊斑块，`blur ≥ 60px`，透明度 25%~40%），光晕颜色呼应字形渐变。
4. **页面底色**：浅灰 `#f0f0ee` ~ `#f5f5f3`，禁止纯白通底。

纪律：
- 光晕只出现在 Hero 主视觉背后，禁止在正文区滥用彩色光斑。
- 胶囊导航、胶囊按钮、胶囊标签统一全圆角；卡片用 16~24px 圆角。
- 移动端：主视觉移至文案下方，光晕缩小但不删除。

## 八、交付自检清单

- [ ] UI 组件主视觉色相 ≤3；渐变只出现在品牌层（图标/logo/hero），未外溢到组件
- [ ] 正文对比度 ≥4.5:1（大标题 ≥3:1）
- [ ] 间距全部取自节奏刻度
- [ ] 字体 ≤2 款，气质匹配任务
- [ ] 一屏内主按钮 ≤1 个
- [ ] 动效有反馈意义且可被系统偏好关闭
- [ ] 图标：squircle 圆角 22%~24%、粗圆笔触、对角渐变、四周留白 18%~22%
- [ ] Hero：悬浮胶囊导航、光晕仅限主视觉背后、浅灰非纯白底
