# niugu-interface — 界面视觉纪律

## 〇、优先级声明

本技能**高于**模型默认的组件使用与配色惯性。禁止无理由套用 UI 库默认外观、禁止霓虹渐变、禁止杂乱撞色。

---

## 一、配色（最高优先级）

1. **色相 ≤3**：主色 + 辅助色 + 中性色，仅此三类。
2. **暖色优先**：米白、暖灰、赭橙基调；冷色仅在与品牌强绑定时使用。
3. **禁止**：
   - 霓虹渐变、高饱和撞色堆叠
   - 一屏超过 3 种主视觉色
   - 纯黑 `#000000` 文字（用暖墨 `#2d2a26` 替代）
   - 纯白背景大面积留白与低对比灰字叠加
4. **对比度达 WCAG AA**：正文 ≥4.5:1，大标题 ≥3:1。交付前必须自检。

推荐基线色板（可整体替换但结构不变）：
- 底色 `#faf7f2`（米白）/ 分层底 `#f3ece2`
- 墨色 `#2d2a26`（正文）/ 次级 `#8a8378`
- 强调 `#c96f2e`（暖橙，仅用于关键动作与当前态）

## 二、字体（按任务气质选择）

| 任务气质 | 字体方向 | 示例 |
| --- | --- | --- |
| 工具/效率 | 无衬线、中性、高 x-height | Inter, system-ui |
| 内容/阅读 | 正文衬线或人文无衬线 | Georgia, Source Han Serif |
| 品牌/落地页 | 有性格的展示字体，仅标题用 | 标题 1 款 + 正文 1 款，最多两款 |

规则：正文 ≥16px、行高 1.5~1.7；字号阶梯 ≤6 级；禁止用 `italic`/`bold` 补偿字号层级。

## 三、间距与布局

- **节奏刻度**：4 / 8 / 12 / 16 / 24 / 32 / 48，禁止随手魔法数。
- 容器最大宽度：正文阅读 65~75ch，工具界面 ≤1280px。
- 对齐方式一屏内 ≤2 种；留白是设计手段，不为填满而堆组件。
- 网格：列间距取刻度值，断点 3 档足够（移动 / 平板 / 桌面）。

## 四、组件纪律

- 禁止无理由套默认组件库外观：组件必须体现本技能配色与间距刻度。
- 按钮：一屏一个主按钮（强调色），次级用描边或文本按钮。
- 表单：标签上置，错误就地显示，禁止仅靠颜色表达状态（加图标/文字）。
- 列表与卡片：同级视觉权重一致，禁止随机强调。
- 阴影：低透明度、大模糊、小位移（如 `0 4px 12px rgba(45,42,38,.08)`），禁止重投影。
- 圆角：统一一档（6~10px），禁止混用直角与大圆角。

## 五、动效

- 时长 150~250ms，缓动用 `ease-out` 系。
- 动效只用于反馈（进入、切换、确认），禁止装饰性循环动画。
- 遵守 `prefers-reduced-motion`。

## 六、交付自检清单

- [ ] 主视觉色相 ≤3，无霓虹渐变
- [ ] 正文对比度 ≥4.5:1（大标题 ≥3:1）
- [ ] 间距全部取自节奏刻度
- [ ] 字体 ≤2 款，气质匹配任务
- [ ] 一屏内主按钮 ≤1 个
- [ ] 动效有反馈意义且可被系统偏好关闭
